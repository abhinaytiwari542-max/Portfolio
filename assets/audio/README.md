# Background track

The vinyl player looks for `track.mp3` in this folder.

Drop in any audio file you have the right to publish, rename it `track.mp3`,
and the player picks it up with no code change. If the file is absent the
widget hides itself, so the site is never left with a dead control.

To change the title shown next to the record, edit `data-title` / `data-artist`
on the `.vinyl` element in each page.

**Licensing:** this folder is served publicly from the site and the repo is
public, so only put audio here that you own or that is licensed for
redistribution (CC0, Creative Commons with attribution, or a track you bought
a distribution licence for). A commercial single ripped from a download site
is not that, however common it is.
